Developed a web-based hospital appointment scheduling system that automates patient booking and doctor slot management. The system prioritizes patients based on urgency levels (Emergency, High, Medium, and Low) and uses Greedy Algorithm, Genetic Algorithm, and Simulated Annealing to optimize appointment scheduling, reduce waiting time, minimize scheduling conflicts, and improve doctor utilization. The application was built using Flask as the backend, SQLite for database management, and HTML/CSS for the user interface.
